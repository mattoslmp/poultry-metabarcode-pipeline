# Methodology implemented by the PRJNA400142 pipeline

This repository implements the poultry respiratory 16S V4 workflow for BioProject PRJNA400142.

## Sequencing and preprocessing

Libraries were generated from the V4 region of the 16S rRNA gene and sequenced as single-end reads on an Ion PGM platform. Reads are filtered with PRINSEQ-lite using a length threshold greater than 100 bp and a quality threshold of Phred 30.

## Primer removal and ASV inference

The 515F/806R primer pair and reverse-complement sequences are removed with the QIIME 2 Cutadapt plugin, release 2024.10, using 5-prime anchored matching and a minimum overlap of 15 nucleotides. DADA2 is then run in single-end mode with trim-left 0, trunc-len 0, learned error modelling, and consensus chimera removal.

## Taxonomy

Representative ASVs are classified with QIIME 2 feature-classifier classify-sklearn using a pretrained Greengenes2 2024.09 V4 Naive Bayes classifier compatible with scikit-learn 1.4.2. Taxonomic summaries are generated by grouping samples by body site, lung versus trachea, at class level L3 and genus level L6. Missing or unassigned labels are displayed as Unclassified.

## Genus-level Venn and heatmap

A genus is considered present at a body site when at least one read is observed in at least one sample from that site. Genera are separated into lung-only, shared, and trachea-only groups. The heatmap uses summed site counts for the same genera and applies a pseudo-log10 scale: zero values are plotted as 10^-1 and positive counts are plotted as log10(count).

## Alpha diversity

Shannon diversity is calculated after rarefaction to 7,503 sequences per sample using QIIME 2 core-metrics-phylogenetic. Lung and trachea Shannon vectors are compared with a two-sided Kruskal-Wallis test, reporting H and p-value.

## Data availability

Input sequencing data are retrieved from NCBI SRA BioProject PRJNA400142.

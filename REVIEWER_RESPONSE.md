# Reviewer response: sequencing analysis reporting

## Reviewer concern

The sequencing analysis requires clearer reporting. In particular, the manuscript mentions rarefaction to 7,503 sequences per sample and the use of Shannon diversity with Kruskal-Wallis testing, but only Shannon diversity was reported. The reviewer requested read counts per sample after filtering, number of ASVs per sample, and a clearer rarefaction justification.

## Response

We thank the reviewer for this important comment. We revised the sequencing methods and results to report the sequencing workflow more transparently. The revised analysis now includes a per-sample sequencing summary generated directly from the FASTQ/QIIME 2 outputs, including raw FASTQ read counts, PRINSEQ-filtered read counts, DADA2 denoising statistics, non-rarefied feature-table counts, ASVs detected per sample, rarefied counts, ASVs retained after rarefaction, and whether each sample was retained at the selected rarefaction depth.

Rarefaction to 7,503 sequences per sample was used to normalize sequencing depth across samples before alpha-diversity estimation. This step was used to reduce sampling-depth bias and allow Shannon diversity and Kruskal-Wallis comparisons to be performed at a common sequencing depth across lung and trachea samples. We clarified this rationale in the Methods and added reviewer-facing comments in the revised manuscript.
